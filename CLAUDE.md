# Moneta: instruções do projeto

App local (Node, `server.js` + `public/index.html`) para centralizar o património do utilizador.

## Regras

- Cores: segue sempre @rule.md (tema escuro preto + verde). Não introduzir outras cores de marca.
- Trabalho de interface: lê @DESIGN.md para a direção e usa a skill `antislop` como filtro (modo "durante"). Sem travessões (—) em texto da interface.
- Edita o código fonte diretamente; não acrescentes funcionalidades com scripts que reescrevem ficheiros.
